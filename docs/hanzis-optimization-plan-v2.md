## 1. 目标与成功标准

让访客能从查字、笔顺、诗词或拼音学习出发，完成一次有解释、有练习结果的学习任务；在保持静态网站和本地处理优势的基础上，提高内容准确性、页面可理解性和使用体验。

成功标准：

- 栏目入口符合用户指定顺序，桌面、手机和中英文界面一致。
- 核心页面提供清楚的方法、具体示例和可实际使用的工具结果。
- 学习正文与版权资料分层展示，许可记录准确、可访问。
- 保留合理的规范网址和索引策略，不为页面数量扩大索引。
- 广告清理、内容审校、技术验证分别有证据；重新申请 AdSense 以实际改进和后台提示为依据。
- 不承诺审核通过、流量或排名，不以固定字数、篇数或自然流量作为官方门槛。

## 8. P1：拼音难点与游戏反馈

先复用现有拼音页面，不立即新增独立指南栏目。首批规划两个难点单元：

- **送气与不送气的区分**：用 b/p、d/t、g/k 等对比组织示例，区分呼读音与实际拼读；说明、音频和练习选项相互对应。教学事实与示范音频需专项核对。
- **ü 的拼写与输入**：区分真实拼写规则与本站接受 `v` 的输入便利；使用已有题库可覆盖的例子和解释，不把“程序判对”当作完整教学规则。

声调页保留已有曲线、调值和例字，按实际发现补缺，不重复填充同类文字。

游戏首批工作：

1. 核对拼音快答错误分类、正确答案和结果列表，给相关难点提供可到达的复习入口。
2. 若课程题目与游戏现有题库不匹配，先补题目映射或仅链接一般练习，不声称已支持专项训练。
3. 先审校新增示例及受影响题目，再按有限批次覆盖词语消除的 120 个词、成语接龙的 36 个环节和每日成语答案。
4. 更正有证据的错误并记录条目，未完成审校的范围如实标记；不通过批量删除提示宣称完成。

验收：至少覆盖正确答案、声调错误、拼写错误、跳过及结果复习；新增说明中英文界面可读；汉字、音节和词典原文不被界面翻译替换。

## 10. SEO、广告与索引分别管理

| 页面类别 | 搜索策略 | 广告策略 |
| --- | --- | --- |
| 现有固定工具入口 | 保持独立标题、描述、规范网址与静态说明 | 本轮移除 Adsterra，不自动启用 Google 广告 |
| 30 首精选诗 | 保持现有静态 URL；逐步深化正文 | 未来投放另行核对页面内容与位置 |
| 新场景/精选学习页 | 具备独立内容及可用功能后加入 sitemap；canonical 指向自身 | 单独评估，不因被索引就默认放广告 |
| 参数查询与输入状态 | 保留对应入口 canonical；不主动把全部参数组合加入 sitemap | 不因 canonical 合并就视为广告政策豁免 |
| 扩展 `/poetry/read/` | 保持 `noindex, follow`，允许爬虫读取该指令 | 本轮随全站清理移除 Adsterra；未来不默认投放 |
| 404、错误或空结果状态 | 保持正确状态和必要索引限制 | 不加入广告 |

版权页是公开可访问的说明页，不通过隐藏或禁止访问规避来源展示。更新现有内链、`public/llms.txt` 等导航说明时使用实际新路径。

`meta keywords` 可在相关维护中简化，但不作为优化成效或过审条件。Search Console 的正常规范化排除无需“清零”；Googlebot 抓取正常不等于 AdSense 抓取或审核已通过。

### 11.2 工程与内容验证

- 导航：375px 手机和桌面、中英文、键盘访问、栏目高亮、移动菜单关闭、Logo 返回首页。
- 广告：构建产物搜索 + 首页/笔顺/字典/诗词/拼音/游戏的 Network；不是测试第三方广告投放成功率。
- 版权：关于入口、旧来源链接、许可下载、词典分组与原文完整性。
- 字帖：场景预设、旧设置不被静默覆盖、诗词直接导入、刷新/撤销、200 字边界、超过上限提示、PDF/PNG/打印预览。
- 诗词：正文和注释、查字弹窗、朗读/拼音切换、收藏/背诵、生成字帖和返回。
- 拼音/游戏：正确与错误分支、答案解释、回看和复习链接；实际发音核对与文件存在性检查分开记录。
- SEO：新增页初始 HTML、标题/描述/canonical、sitemap、结构化数据和可见内容一致；原参数规则及 noindex 保持。
- 内容：事实、读音、语境、来源、编辑/审校范围有记录。人工未完成的项目标记“未验证”，不靠构建通过代替。

实施时优先使用现有检查：`npm run check`、`npm run build`、`npm run release:verify`，以及受影响的 `tests/e2e/seo.spec.ts`、`i18n.spec.ts`、`release.spec.ts`、诗词/字典/游戏专项。导航纯重排不另建大量镜像单测；新增行为才增加必要用例。

文档制定阶段只检查文档结构、路径与事实一致性，不运行构建或业务测试。实施完成后区分本地通过、生产通过、实体打印/设备验证与后台审核状态。

## 12. 效果观察与重新申请

### 12.1 衡量是否对用户有帮助

- 搜索发现：按页面和查询观察展示、点击、点击率、平均排名；Search Console 不用于统计站内停留时长。
- 工具任务：如后续启用最小事件统计，分别观察预览就绪、导出成功/失败、从诗词进入字帖、练习完成、错题复习。
- 指标口径：导出成功率采用“成功次数/导出尝试次数”，学习完成率采用“完成轮次/开始轮次”；区分页面、语言、设备和观察区间，不把少量样本当成确定提升。
- 隐私：事件只记录必要结果和错误类别，不上传用户输入文字；是否接入新统计服务、存储标识及隐私说明按实际方案另行评估。本方案不自动接入第三方统计。
- 内容维护：记录问题报告、修正条目和实际审校覆盖率；短时间完成打印任务不因停留短被判断为失败。
